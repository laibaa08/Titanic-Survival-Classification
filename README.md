This project is an end-to-end machine learning pipeline built on the Titanic dataset to predict passenger survival. It covers the complete workflow of data cleaning, handling missing values, feature engineering, model training, and evaluation, using Python libraries such as Pandas, NumPy, Scikit-Learn, Matplotlib, and Seaborn. The notebook demonstrates performance evaluation through accuracy scores, classification reports, and confusion matrices, making it both practical and beginner-friendly. Designed to run seamlessly in Jupyter Notebook, this project serves as a solid introduction to data science, predictive modeling, and Kaggle competitions.
